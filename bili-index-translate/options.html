OpenAI-compatible root (/chat/completions is appended automatically), or the full translate endpoint when the API format is DeepLX. DeepLX: the Base URL is used as entered, e.g. https://host/translate?token={apiKey}. {apiKey} is replaced with the API Key; without it the key is sent as a Bearer token, and an empty key sends none. A relay prefix, if set, must be the complete relayed endpoint. This format translates selections and Alt+A pages only (a batch of paragraphs goes out as one request, one paragraph per line): Study Card, image translation, the glossary and the model selectors need an OpenAI-compatible endpoint. Target language accepts language names or DeepL codes (ZH, EN, PT-BR).
A preset fills in the Base URL and the fields below; nothing is saved until you press Save. Any service that answers with JSON can be described here.
One Name: value per line. A body is sent as application/json unless a Content-Type is given here.
Placeholders for the Base URL, headers and body: {text} the text to translate · {texts} every text of a request as a JSON array (body only; an Alt+A batch then needs one request) · {apiKey} · {target} the Target language as entered · {targetLang} / {targetLangLower} its code, such as ZH / zh. In a JSON body write "{text}" inside the quotes and {texts} without quotes. The result path says where the translation is in the JSON reply, for example data, translations[0].text, or translations[*].text together with {texts}. Like DeepLX, this format translates selections and Alt+A pages only.
Empty = direct connection to index-translate.bilibili.com (no Python proxy needed). Requests never fall back to a relay on their own: if the direct endpoint answers HTTP 412, the error is shown and you decide. A relay receives your selected text, images and API key, so only enter one you trust.
