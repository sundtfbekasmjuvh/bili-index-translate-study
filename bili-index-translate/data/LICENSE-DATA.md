# Data licenses

Files in this folder are generated by `tools/build-wordlists.py` (repository root).

## hsk30.txt (Chinese word levels)

- Source: https://github.com/ivankra/hsk30 (file `hsk30-expanded.csv`)
- Commit: 4ff9e3915ce87baaecd7ebe263085573a4ea3192 (2023-11-06)
- License declared by the repository: MIT (Copyright (c) 2023 Ivan Krasilnikov). The repository says the data is largely derived from elkmovie/hsk30 and shawkynasr/HSK-official-Query-System, both also MIT.
- Upstream work: the HSK 3.0 word list (language standard GF 0025-2021 (issued by the Ministry of Education and the State Language Commission)). **The copyright status of the official original (GF 0025-2021) is not confirmed.** The MIT label on the GitHub copy does not prove the official owner granted any license. The project owner has accepted this risk.
- Processing: simplified forms only, duplicates removed (a word in several levels keeps the lowest level), levels 7-9 merged into `#7`.

## freq-en.txt, freq-es.txt (word frequency ranks)

- Source: the `wordfreq` Python package (https://github.com/rspeer/wordfreq/), version 3.1.1, author Robyn Speer. Words come from `wordfreq.top_n_list`, filtered to letters only; line number = rank.
- Data license: Creative Commons Attribution-ShareAlike 4.0 (CC BY-SA 4.0), https://creativecommons.org/licenses/by-sa/4.0/. Attribution is required, and derived data must be shared under the same license. (The wordfreq code itself is Apache-2.0.)
- wordfreq's data combines third-party sources, including Wikipedia, subtitles (OpenSubtitles), news, books, web text, Twitter, Reddit and others. See the wordfreq README for the full list and each source's terms.
